# Painterly book cover collection

Generated from the approved lorebook covers in `design/wireframes/premiere-home/jewel-pages/01-library.png`.

Use case: stylized-concept asset. The attached image is a UI reference ONLY for the lorebook cover artwork shown in its bottom shelf. Make a production-ready flat rectangular 2:3 portrait book-cover LAYER asset, straight-on, filling the canvas, no photographed 3D book or mockup scene. Match those painterly dark paper covers with delicate hand-etched antique-gold illustrations and subtly imperfect fine gilded borders. Elegant miniature storybook/tapestry artwork, not vector icons, not generic clipart, not a UI screenshot. No words, letters, title, fake text, numerals, watermark, logos or surrounding UI. Center 40% of the cover remains quiet enough to add an editable title later. Maintain consistent composition and restrained fine line detail across the collection.

Sixty semantic ornaments use transparent backgrounds. Ten painted paper layers use opaque backgrounds. Individual labels and categories are recorded alongside each PNG in `asset.json`. Titles are rendered by the app and are never baked into the layers.
