Carried / New: Carried: the lorebook Changes pane (per-change diff, Revert/Undo/Restore), the scene Cast wing’s card-changed notice with its Back to version N line, and the Updates version timeline (variant B draws it as pips on a track with the selected version’s detail card; variant A keeps the plain log rows carried from Settings’ Updates tab). These three surfaces live in three different rooms in the real app (Workbench/lorebook editor, Scenes, Settings); this reference page shows them stacked with the Dock fixed on Workbench rather than rebuilding three separate shells, since BUILD-BRIEF states there is no standalone history browser to draw as its own room. Phone width is covered by the page-wide Width switch, not repeated here.
