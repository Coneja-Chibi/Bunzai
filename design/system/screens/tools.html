User docs

Edit a piece

Open a piece on the Workbench, change it through the Grid or Steps view, and save your draft explicitly before you close the tab.

The short version

Editing happens on the Workbench. A piece opens there as its own tab, already filled in with whatever your import carried, or with the blank template you started from, and it stays a private draft until you save it.

The editor panels

A character's editor opens with a strip of platform tabs above the fields. The first, labeled Bunzai, is the full card with nothing hidden.

Saving, and what happens if you don't

Every editor requires a name before Save does anything. Save writes your whole draft, not just what changed, so fields you haven't touched round-trip byte-for-byte.

Carried / New: Carried: the Apps catalog grid; CSS Workshop’s Simple/Advanced switch, starters, source and rules cards, sealed preview, and Clear-draft dialog; Docs’ nav/content/table-of-contents three-rail layout plus its mobile Browse and Sections sheets; the Macro Lab’s platform lens, Your text card with pretend-context fields, the engine box (not-installed and installed states), and the Reading/Macro bible/Operations reference tabs; HTML View’s drawing and Fullscreen (the full editor with source is its own screen, htmldoc.editor; here it is the catalog-opened viewer only). Each tool opens with the shared tool header rule from BUILD-BRIEF variant B; variant A keeps each tool’s own plain header instead. Phone width is covered by the page-wide Width switch, not repeated per tool.
