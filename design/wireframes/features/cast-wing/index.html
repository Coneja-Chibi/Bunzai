Cast wing

v2, matched to RoleCall's real Cast wing (CharacterPanel, PersonaPanel, the Casting Call picker; left-wing-groups). Three tabs: Character, Persona, Participants. Each editing tab is a hero card, a tall portrait on the left and a scrolling form on the right with a pinned footer. The forms are the Workbench's own character and persona editors, so one editor each. Square corners and Bunraku tokens throughout; RoleCall's round swatches and glyph marks become square swatches and the icon set.

How saving works. Save writes the Library card, then moves this scene onto the new version; other scenes show Update available. There is no override or fork layer. A swap is this scene only: it never changes your default for new scenes. Only the Default persona button does. Swap, card save and revert all wait while a reply is being written.
