Rules. Primary at most once per view. Danger only for destructive actions, always with the existing confirm. Icon buttons always carry a label. Rows never look like buttons. No room may style a button itself; a guard blocks it.

Under the hood. The Stamp becomes this Button (its hover-lift and shadow stay); RoleCall's ported Button and every room-made one are replaced. Themes still recolor all of it through tokens.

Label case. Sentence case reads like the chooser you liked; all caps matches today's chrome. Pick one; it applies everywhere.

Section 2. Replaces the bare clickable row: every clickable thing is a named type with one shared look. Inventory: 300 rows today; 220 become these types, 76 were really Button, IconButton, Chip, Segmented or Tabs, and the last 4 become a Toggle, a drop Card and two of the types above. Art and per-item colors still pass through (a card's picture, a swatch's color, a deck's tint); the frame, spacing, hover and selected look are shared. Theme variants (title screen skins, Messenger) restyle these types through stable hooks, the way they restyle buttons now.
