Story Director settings

Two places, the same values (ChatStore, one writer each): the Story Director row in the Props wing with its settings block underneath, and the Narrator section in the Control Booth. The switch on the row is the on/off. Default off for every new scene. Copy is RoleCall's; changes are marked.

Only controls that work are drawn. On: on/off, Personality, Model (with Reasoning), Command mode, Temperature, Auto-retry, Creativity, Custom instructions. Not drawn: Max tool rounds and Default AI Awareness (they gain meaning with automatic tracker updates, the later SD-3 slice) and Interactive choices (RoleCall's switch does nothing for the Director). Auto-retry is real here: it allows one corrective pass when the model returns malformed data. Creativity is real here: RoleCall saves it and never reads it; here it is the "creativity level" line in the Director's prompt.
