Story Director: one switch for automatic tracker updates

Drawn twice, once in Bunraku's own look and once as a mock of RoleCall's. Each block has a Today column and a Proposed column. The change: no number hides "off". One switch in the Story Director settings turns automatic tracker updates on or off. When it is on, a short list shows every tracker that is switched on in the scene, each with its own switch and its own "every N replies". A tracker's own settings menu has no control for this; it only says what happens and links to the list. The call budget sits inside the same section and shows only while the switch is on.

What each old number hid. Default AI Awareness: 0 meant manual only. Max Tool Rounds: 1 meant trackers never update. A tracker's DM Updates number: 0 meant never, and an empty value meant follow the scene. Now off is a switch and the smallest N is 1. The call budget is called "Model calls per reply", runs 1 to 5, and has no hidden off value: 1 means one call, not "never".

Behavior. The list has one row for each tracker switched on in the scene; switch a tracker on in the scene and it joins the list, switch it off and it leaves. A row's number starts as the default at the top. Typing in a row changes only that row. The smallest number is 1, so there is no zero and no manual number. A row whose number differs from the default shows a small "Use default" link that puts it back. A row switched off keeps its number but dims it. With the switch off, the section is only the switch and one line; the list and the call budget are hidden. Hover text (RoleCall's first sentence kept, storyboards dropped until they use this): Update trackers automatically. Controls how often enabled trackers ask Story Director to refresh state. Off means trackers change only when you edit or Refresh them.
