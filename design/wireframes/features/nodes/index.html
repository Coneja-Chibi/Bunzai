New parts: NodeCanvas (pan, zoom, minimap), PieceNode, PipelineNode, EngineNode, Wire, BoardNote, BoardFrame. Reused: the Workbench head's segmented switch, Stamp buttons, the kind colors (deck tokens), the Workbench recent rail as the drag source.

Links layer: what a gesture saves
  • Drag a port to a node to link it: Lorebooks port to a lorebook adds it to the character's (or persona's) lorebooks; Behavior to a regex set; a preset's ports to regex sets and quick replies. Same saves the editor makes.
  • Select a wire, press Delete (or Unlink in the inspector) to remove that link. The pieces stay.
  • Double-click a node (or Open in Desk) opens it in the editor.
  • A link to a piece you have not brought up shows as a faded node you can click to bring up.
Pipeline layer: the prompt, built live
  • The preset opens up into its blocks in build order. Drag a block to reorder it, click it to switch it on or off. Those are the preset's own saves.
  • Marker blocks are inputs: the character's description, the persona's, the lore pass and the chat history wire in where they splice.
  • Token counts come from the same build the Context wing's forecast uses. Preview shows the finished request.
  • Pick which scene feeds it (cast, persona, history) from the Request node; with no scene it builds a dry run from the pieces on the canvas.
Board layer: your own notes
  • Add a note, a picture or a frame anywhere. Frames move what is inside them.
  • A note can be pinned to a node; it follows the node around.
  • Board items belong to this workbench, not to the pieces, so exporting a character never carries your notes.
  • Positions of everything on the canvas are remembered per workbench. Tidy up lays the links and pipeline out again.

Questions for you

  • 3. Scenes on the canvas? Not proposed for the first version: a scene isn't a library piece. The Request node picks one to feed the pipeline instead.
