Shown once, when Bunraku opens a studio folder that already holds pieces as plain files: it carries them into the encrypted library, checking each one as it goes. Only pieces move; pictures and other files stay in the folder, and nothing stops the load-in except a full disk. An empty folder never sees this screen.
