01 Lock screen

Shown instead of the Studio whenever the library is locked. With no password, this computer unlocks by itself and the person never sees this screen. It appears only when a password is set, or on a computer the library does not know yet.

State A: a password is set
Your library is locked
Welcome back

Checking takes about two seconds. The app stays usable while it checks.

words = new numbered-cell grid in the chip grammar / remember = SettingsRow + ToggleSwitch

Why these words: the error never says whether the password was "close". "Use recovery words instead" is always one click away, because the words are what rescue a forgotten password. The remember switch is off-limits while a password exists, matching the rule that a computer's copy never sits beside a password.
