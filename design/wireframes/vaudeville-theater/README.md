# Vaudeville theater directions

Design studies, 2026-10-02. The previous paper-theater direction was rejected.
These are atmospheric versions following the existing Vaudeville design
system, retaining dark paper and a cute, slightly gamey puppet-theater entry.

## Authority

Read from the Vaudeville design system (kept outside this repository):
`IMPORTANT READ ALL/AESTHETIC.md`, `CHEATSHEET.md`, `PATTERNS.md`, `PAPER.md`,
`README.md`, `SKILL.md`, `colors_and_type.css`, the stage-wash/button previews,
and the Plotlight UI kit. HTML links that actual token sheet rather than recreating
its colors. Cinzel is local; the source sheet requests its other house fonts online.

The core is velvet canvas, opaque panels, saturated rose/violet/gilt, hard black
frames and offset shadows, Cinzel marquee, serif voice and mono readouts. Paper
depth lives in scenic cutout planes and the folded mascot. No grain, glass,
soft card shadows or pastel app panels. All illustrations are original SVG.

## Three compositions

1. **Velvet stage:** centered proscenium, crimson curtains and gilt footlights.
2. **Moonlit shadowbox:** left editorial title, right layered puppet diorama.
3. **Midnight matinee:** cinematic title and illustrated feature poster.

Each includes Entry, Home, Library, Scene and Editor, with phone-container layouts.
These five screens establish visual direction; they are not exhaustive interaction
or state specifications. Portrait scenery is placeholder artwork, not a proposed
replacement for real character portraits. Counts, conversations and text are samples.
Buttons never call the app, modify a library or send a model request.

Open [index.html](index.html). Query options: `direction=velvet|moon|cinema`,
`screen=entry|home|library|scene|editor`, `width=phone`.

Design approval and production adoption remain separate. No app source changed.
