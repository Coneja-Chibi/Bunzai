Scene backdrops (where you pick a background)

SillyTavern keeps a folder of background images and lets a chat pick one. Bunzai has no home for that today: the only backdrop is a theme slot (theme-owned, not your art), and a character's creator-picked background has no place that shows it. This page shows where a person would pick a backdrop, so the 39 images in the ST folder have somewhere to land. Awaiting approval. Nothing here is built.

4. Where the images live: the three options (you choose)
A. A backdrop on the scene only smallest
The scene stores its own image bytes. No shelf: you pick a file per scene. 39 imported backgrounds have nowhere to wait, so a bulk import cannot land.
B. A new kind, Backdrop new storage
A Library deck of backdrops, a format adapter that reads image files, and the scene points at one. Cleanest for the shelf and for import. It adds a new entity kind, which is a new piece of storage and needs your approval.
C. Reuse the Sprite pack no new kind
A pack named "SillyTavern backgrounds" holds the 39 images (the pack already stores art through the sealed image path and has a deck and an editor). The scene points at one pack item. The cost: the pack's wording is about expressions, and it has no importer yet, so one small adapter for image folders is still needed.

Recommendation: C with the scene row from screen 1. It gives the 39 images a shelf and an editor with no new storage kind. The scene stores only a reference (pack and item), the picker in screen 2 reads the pack, and the pack's own wording gets a small tweak (Sprite packs become "Packs", art and expressions). If you want backdrops to feel like their own thing in the Library, B is the honest alternative, and it is the only one that is a new storage authority.

New, called out: one scene row, one picker dialog, and one reference field on the scene. Every control in them is an existing component. Nothing else is invented.
