What makes it friendly and what stays the same underneath

  • Starts from a recipe, never an empty canvas. Templates show their shape as a tiny strip of steps.
  • Built on phases. The track up top is the turn: private phases first, then the reply, then the tidy-up. Each phase lists what it reads, what it can use, and what it gets from the phases before it; the hand-off lines say it in words.
  • Plain sentences. "when the chat mentions a fight" instead of a pattern. Patterns stay one link away.
  • Edit in place. A phase opens right where it is (Write); the others stay folded to one line.
  • Try a line. Rehearsal as a playful check: type a line, watch the steps light up. Lit steps glow on the list too.
  • Extras appear only when used. No tools, notes or regex until you add one; the tidy line shows up once a regex set is chosen.
  • Cards. The same book as a hands-on board: each phase is a column. Cards stacked top to bottom go in that order; cards in one dashed row go in together. "+ New phase" adds a column.
  • Six kinds of card. Prompt (text the phase always reads), Skill (text that turns on only when needed: always, when the chat mentions something, or when the model picks it from the skill names and descriptions; it stays on until that ends or the model is done with it), Tool (an action the model can call), Dice (a roll or random table), Regex (find and replace), Agent (who runs the phase, from its "Run by" seat). Each has a label and glyph, so the kind reads without color.
  • Board is one switch away. Phases and Board are the same book. The board shows the same phases as nodes, with the wires, for people who want them.
