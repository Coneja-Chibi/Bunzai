Choose formats and review export reports in the Press.

  1. 1 Playbill header. Today the room has no header, only a row of platform chips. The title, a one-line lede, the status line, Reload Studio and Clear the queue now live in one header. Clear the queue moves here from the footer, still hidden while printing.
  2. 2 Target platforms become a wall of cards, ahead of the queue, because the target decides every readiness line below. One pick per run, rose edge on the chosen one. Each card also names the piece kinds the adapter prints (read from the existing per-kind adapter list, and the CCv3 borrowed note for extension-map hosts).
  3. 3 The library rail keeps its click-to-stage list, now with deck-colored kind edges. Offers hide anything already staged; when all are staged it says "everything is staged".
  4. 4 The room is numbered as three beats (target, stage, print). Bundles are panels with a deck edge and a Cinzel title; the counts of staged and dropped pieces sit beside the section title. Unstage stays on each bundle.
  5. 5 Each piece keeps its readiness line, an Open in the editor link for warnings, the filename field and the file type segment (shown only for text formats, only before a run). The tone dot becomes a text badge (Ready, Notes, Won't fire) so color is never the only signal. Riders are indented with a gold dashed rail and keep drop from this run and ride again.
  6. 6 The footer becomes the run bar: piece count, the fold summary, the target and the zip name it will produce, then a large Run the press. Disabled without a platform or any pieces (tooltip: Pick a target platform first).
  7. 7 Run states: printing, printed, printed with notes, failed with its message, skipped with its reason, plus filename, carries line and Download the bundle / Clear the results. These replace the filename editor on each row once a run exists.
  8. 8 Empty queue and the two library notes (everything staged, studio unreachable) get real panels instead of loose gray text.
  9. 9 The overlay widget "On the press" is restyled in the same panel and type, nothing added or removed.
