  1. One header for every kind. The approved editor header: monogram on the kind's deck color, name in Cinzel, one meta line, save state, focus. A tracker's meta says where it is linked.
  2. Tracker settings sit in the Identity disclosure, like a preset's: what it tracks, how the AI should update it (this text goes into the update tool), shape (one record or a list of rows), and an optional prompt line written with macros. Blank prompt line means the plain line.
  3. Fields list on the left, one field's page in the middle. The same field editor serves trackers and tools (one component; only the tool adds "the AI must fill it", only the tracker adds ranges and a starting value). No limit on how many fields.
  4. Type decides what follows: Number shows From, To and Starts at (blank means open); Choice shows the choices as chips; Yes or no a two-way switch; Text a starting text. Click the segments.
  5. Right rail shows exactly what the AI gets: the line it reads every turn (rendered with sample values), and the tracker's line inside the shared update tool. The token count is the real cost per reply, instead of any cap or warning.
  6. Tool fields use the same field editor. The rail shows the tool's name and what it takes, its cost per reply, and a Try tab that calls it and shows the answer the AI would get.
  7. One choice for what the tool does: roll the dice the AI gives, roll a dice piece, run a formula, or just note it. Each shows only its own picker. Click the segments.
  8. Dice is one small page. Roll, Table or Pool, each with a one-line roll card (field, result, Roll), the way the TTRPG cards read. A table shows each row's chance, and the last roll lights its row. No row, side or dice limits.
  9. Formula text in monospace with the macro chips under it, including the four word-watching macros and the tracker macro.
  10. Try it runs the formula on a copy of a scene you pick, and shows the result and how long it took. When the reply's tool time runs out, the run says so and names the macro that was still working (second result, shown for the wireframe).
  11. Show changes on replies as (approved option D): chips, a card, a toast, or hidden, per tracker. The scene setting turns change visuals on or off.
  12. An icon per field (and per list, in its settings), used by the tracker tiles, pips and change chips. From a small built-in set; None is allowed.
  13. To can be another field: a number's top can be a fixed number, another number field (HP out of Max HP), or none. A top makes the field a bar.
