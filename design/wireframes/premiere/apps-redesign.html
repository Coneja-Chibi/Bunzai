The Workbench

The bench where pieces are edited. Open pieces are staged here from the tab strip above; one is being edited, and any of them may carry edits that are not on disk yet.

The Library

Every piece in the studio, sorted into decks, plus anything on disk that would not open.

Scenes

Every story you have going: pick up where you left off, start a new scene, and choose how it looks. 6

The Press

The staged conversion queue. Pieces are staged here from the Library, one target platform is chosen for the whole run, and the run prints them into a single zip.

The Agent

The agent's own window. Shows what it can see on the screen you were last standing on, and the brief it would be given.

Included apps Specialist tools, bundled and ready, kept off the Dock 4

CSS Workshop

Assisted CSS authoring room. Starters, property knobs, plain CSS source, sealed preview. Copy or download for any host.

Macro Lab

A scratch pad for macro text. The reading half explains each token against the catalog for the chosen platform and shows what it becomes on the other four. The resolved half runs the text through that platform's real macro engine, when a checkout of it is installed on this machine.

Help / Docs

Everything about Bunzai, readable here or on GitHub from the same source.

HTML View

Draws a page as a full tab. Write it in an html block; the person opens it, no tool does. Sealed and offline: all CSS works, images only as data: URIs. No JavaScript, no iframe, form, input or button, no http(s) image, font or fetch. Static wireframes and mockups only.
