Get started

5 sections·6 min read·docs/guide/getting-started.md

Getting started is four things: install Bunzai, run the first-run wizard once, learn the rooms the Dock shows you, and bring your first file into the Library. The wizard does not restrict what you can make or publish.

The short version

  1. Install Bunzai. Download the build for your platform from Releases. To run from source instead, install Bun 1.3+ and use:
# clone, enter, install
git clone https://github.com/Coneja-Chibi/Bunzai.git
cd Bunzai
bun install
5
  1. Open the studio. Run the downloaded app, or from a source checkout:
bun run dev

This starts the primary loopback server and prints its address, 127.0.0.1:8321 by default. Open that in your browser.

Optional remote listeners stay off until you enable Remote access in Settings.

The first-run wizard

It asks four questions, once. Skip it and the defaults apply; Settings keeps every choice that matters after setup.

The Dock

Rooms and decks

The Dock along the bottom lists every room. Each deck kind keeps its own colour edge, so a lorebook never looks like a preset.

Bringing in your first file

Drop a card, a lorebook or a preset onto the Library, or use Import. Bunzai detects the format and keeps the original untouched.
