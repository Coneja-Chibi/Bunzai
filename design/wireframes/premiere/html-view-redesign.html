What this tab draws The authoring notes the agent is given 7

What renders

  • Grid, flexbox, custom properties, gradients, transforms, animations, media and container queries.
  • Inline style blocks and style attributes, tables, semantic layout, inline SVG, unicode.

What is dropped, silently

  • Script and every event attribute: no JavaScript runs.
  • iframe, object, embed, form, input, button, textarea, select, link, meta and base are stripped.
  • No http(s) request resolves: remote images are blank, webfonts fall back, images must be data: URIs.
