Callouts what each number shows

  1. Phase node. One step of the turn (astrsk's agent card): Pages, Tools, Output and Preview tiles each open the side panel. Same model as the scene unless you pick another. Output "Hidden" means the phase writes notes for later phases, not the reply.
  2. If node. True and False exits. Its test uses TavernAI 2's trigger style: keyword or regex over the whole chat, the last message, or the last N.
  3. Selected phase. Accent outline; the open tile (Pages) shows its list in the side panel, with Table of contents and Bookmarks as opt-in switches per Promptbook.
  4. Regex node on a wire. A regex set runs at that point: before a phase sends, or after the reply. Same regex sets as the Library.
  5. Tool node. A schema the model may call (built-in actions only, Kit risk tiers). Wire it to the phases allowed to use it.
  6. Margin notes. Small state the phases read and write (dashed wires = reads and writes, not turn order).
  7. Conditional block (TavernAI 2). Goes in only while its trigger matches.
  8. Not firing now. Dimmed, so you see what this turn actually sends.
  9. Block variants (TavernAI 2). Swipe between versions of one block without losing the working one.

Same nodes or not? Two sets, one board. The book level has turn-shaped nodes (Start, Phase, If, Tool, Regex, Notes, End). The block level is today's Pipeline: TavernAI 2's ideas are not new nodes there but settings on a block (When, Variants) and a frame around blocks (Merge group). A preset is just one phase with no book around it, so the ladder Script Sheet, Preset, Promptbook works without a new editor.
