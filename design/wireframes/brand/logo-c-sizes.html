What changes by size: the tilt goes below 128 px (tilted edges blur into mush); the tear line and punch hole go below 64 (the stub end becomes a solid darker band); below 48 the ticket gets taller so it fills the square, and a whole bunny head (two ears and a round face) is punched out; at 16 to 20 that head is drawn on the pixel grid so it stays crisp. A thin paper-colored rim keeps it from sinking into dark taskbars. Windows .ico files hold each size as its own drawing, so the app picks the right one automatically.
