The Press, soft identity. Ported from press/index.tsx, press-core.ts, press-bundles.ts, readiness-core.ts. The left rail lists unstaged studio pieces as stamps (click to stage); the queue groups staged pieces into bundles (a character's linked lorebooks ride along, "ride again" / "drop from this run" per rider) and solos. Readiness shows before a run: a lorebook's own keyword check (red = will never fire, amber = some missing, no target needed), a character against the picked platform's coverage with an "open in the editor" fix link, and "no target picked yet" when none is chosen. Once a target is picked, each waiting row gets its filename and flavor pick (.json/.txt/.md). Run the press settles every row as printed (with a carries note), printed with a dropped-fields warning, skipped (target has no format for that kind), or failed (with the reason); download the bundle appears once at least one row prints (source hands over one bare file for a single print, a zip for more than one - not drawn separately here since it is the same button).
